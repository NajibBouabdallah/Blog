## 2025-07-08 - Zero-State Repository UX
**Learning:** The "empty repository" state is a missed UX opportunity. A minimal README (e.g., just the project name) provides zero guidance, making the initial developer or visitor experience confusing and uninviting.
**Action:** When encountering a "clean slate" project, initialize it with a high-quality README that sets standards for accessibility, mission, and visual delight to establish a positive UX foundation immediately.
