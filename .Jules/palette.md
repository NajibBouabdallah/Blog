## 2024-07-16 - Accessible Foundation
**Learning:** Starting with an accessible HTML foundation (skip links, landmarks) ensures a better UX from day one.
**Action:** Use semantic HTML and skip links in initial project setup.

## 2026-07-17 - Accessible Asynchronous Forms
**Learning:** For asynchronous form submissions, screen-reader-friendly status updates via `aria-live="polite"` combined with temporary disabling of controls prevents duplicate requests while providing a reassuring feedback loop.
**Action:** Use `role="status"` and `aria-live="polite"` alongside loading indicators and disabled states to build fully accessible dynamic forms.
